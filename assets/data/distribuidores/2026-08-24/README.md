# Captura do diretório de distribuidores

Captura estática realizada em 24/08/2026 a partir do diretório oficial da Hágil.

- `diretorio-grandes.html`: resposta oficial usada para normalizar 55 distribuidores de grandes animais.
- `diretorio-pet.jpg`: quadro oficial usado para normalizar 17 distribuidores e pontos de venda Pet.
- Fonte: https://hagil.com.br/distribuidores-da-hagil
- Dados normalizados consumidos pelo site: `js/distribuidores.js`.

Os pontos do mapa usam a UF representativa da área de cobertura informada. A lista textual mantém cidade, UF, contatos, links e quantidade de municípios encontrados na fonte.
